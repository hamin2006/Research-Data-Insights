# Architecture Deep Dive

## Architecture

![Archnitecture Diagram](./media/RDI-Architecture-Diagram.png)

1. The user request is first sent through a security layer which comprises of AWS WAF, Amazon CloudFront, and AWS Shield for flagging any potential threats.

2. Users access the application through a React frontend hosted on AWS Amplify. AWS Cognito handles user authentication, ensuring that only authorized users can log in and interact with the platform.

3. The frontend communicates with backend services via REST API (API Gateway → Lambda) for CRUD operations, user management, and research agenda operations. Access is controlled using IAM roles and policies.

4. When users create research agendas, they can upload context documents and research observations to S3 buckets via presigned URLs generated by Lambda functions.

5. Document processing Lambda functions extract text from uploaded files and generate embeddings using Amazon Bedrock. These embeddings are stored in Amazon RDS with pgvector extension for similarity search.

6. Research agenda metadata, user interactions, chat sessions, and collaborator information are stored in Amazon RDS via RDS Proxy to optimize database connections.

7. When users ask questions in chat sessions, the system performs RAG (Retrieval-Augmented Generation) by searching relevant context documents and observations using vector similarity.

8. Amazon Bedrock processes user queries with retrieved context, generating responses using foundation models. The system tracks which documents were used for each interaction.

9. Chat sessions and user interactions are stored in RDS, enabling conversation history and collaborative research features.

AWS CodePipeline and CodeBuild automates Docker image builds and Lambda deployments for seamless backend updates.

### `users` table

| Column Name      | Description                                    |
| ---------------- | ------------------------------------------     |
| `user_id`        | UUID, primary key                              |
| `cognito_id`      | Cognito identity ID                           |
| `user_email`      | Unique email of the user                       |
| `username`        | Username of the user                          |
| `first_name`      | User's first name                             |
| `last_name`        | User's last name                             |
| `time_account_created`      | Timestamp of account creation       |
| `roles`        | Array of user roles (e.g. member, researcher, admin)         |
| `last_sign_in`      | Timestamp of last sign-in        |
